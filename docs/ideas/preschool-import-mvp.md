# MVP 사업 구조 + 적대적 분석: 해외 오픈 커리큘럼 기반 예비초등 프로그램

> 작성일: 2026-08-24 · 전제: 국내 사업, 1인 운영, 저예산 · 원천: Oak National Academy(OGL)·EYFS(OGL)·Head Start ELOF(퍼블릭도메인)·IM K-5/EL Education(CC BY) + 누리과정·2022 개정 교육과정 고시문(저작권 無)

## 1. 시장 팩트 (2025년 교육부 첫 공식 조사)

- 영유아 사교육비 3개월 8,154억 원(연 환산 ~3.3조), **5세 사교육 참여율 81.2%**
- 1인당 월평균 33.2만 원, 영어유치원 월 154.5만 원 — 지불 의사는 검증됨
- 예비초등 코호트: 연 30만 명대, **매년 신규 리필되는 시즌 시장**(9월~익년 2월 피크)

## 2. MVP 설계 (v1)

**포지셔닝**: "영국 국가 커리큘럼(EYFS) 기반, 초등 입학 준비 12주 홈스쿨 프로그램" — 학습기·방문교사 없이 부모가 하루 20분 진행

**퍼널**:
1. **무료 진단 (리드 확보)**: EYFS Early Learning Goals + Head Start ELOF를 한국 초1 성취기준에 매핑한 "예비초등 준비도 진단" 웹 도구. 결과지에 크로스워크 근거 공개 → 신뢰 + 카카오채널 구독 전환
2. **무료 콘텐츠 (SEO/AEO)**: "7세 한글 떼기 로드맵", "초등 입학 준비 체크리스트" 등 — 진단 도구로 연결 (AI가 글을 인용해도 진단은 방문해야 함 → 1차 분석의 AEO 역설 회피 구조)
3. **유료 상품**: 12주 프로그램 — 주간 활동 가이드(PDF+웹) + 카카오 주간 미션 알림 + 월 1회 부모 라이브 Q&A. 가격 39,000~59,000원 패키지(윙크 류 월 10만 원+ 대비 1/10 포지션)

**콘텐츠 소싱 원칙** (적대적 분석 반영, §4-3 참고):
- 수학·과학 탐구·영어: Oak/IM/EL 번역·재구성 (해외 자료의 실제 강점 영역)
- 한글 문해·학교 적응: 국내 공공자료(국가기초학력지원포털, 고시문) 기반 자체 제작 — **해외 자료로 한글은 못 가르친다**
- 모든 자료에 출처표시 + 변경 명시, 제3자 저작물(사진·지문) 제거, Oak/IM 로고·명칭 미사용

**빌드**: 4주 (1주 크로스워크 매핑 → 2주 진단 도구 + 12주 중 4주분 콘텐츠 → 1주 결제·채널 연결). 비용 ≈ 도메인+결제수수료. 통신판매업 신고 필요(콘텐츠 판매 형태 유지 시 학원법 비적용).

## 4. 적대적 분석

### 4-1. 수요 공격: "영국 커리큘럼"이 한국 학부모에게 먹히는가?
- 한국 예비초등 불안의 실체는 **한글 떼기, 받아쓰기, 기초 연산, 40분 착석·학교 적응** — 지극히 한국적 수요이고 EYFS에는 한글이 없다.
- 영국 초등 수학은 한국보다 진도가 느리다. 진도 경쟁에 민감한 학부모에게 "선진"이 아니라 **"느슨함"으로 읽힐 역풍** 가능. "영국식" 소구가 실제로 강한 곳은 영어·탐구·놀이학습 영역뿐.
- **반영**: 해외 커리큘럼을 전면에 세우지 말고 "초1 성취기준 준거 + 영국식 방법론"의 하이브리드로. 헤드라인은 한국 학부모의 불안(입학 준비)으로, 영국 커리큘럼은 신뢰 근거로만.

### 4-2. 경쟁 공격: 5세의 81%가 이미 뭔가 하고 있다
- 윙크(3~9세 블렌디드, 예비초등 전용 콘텐츠), 밀크T 아이, 아이스크림 리틀홈런, 스마트올 쿠키, 엘리하이 키즈 — 대기업들이 TV 광고로 전쟁 중인 레드오션.
- 신규 1인 사업자가 콘텐츠 물량·학습기·관리교사로는 절대 못 이김.
- **반영**: 정면전 회피. 니치 = ① 학습기 거부/홈스쿨 성향 부모 ② 월 10만 원 학습지가 부담스러운 가격 민감층 ③ "진단→맞춤"이라는 대기업이 안 하는 앞단. 시장의 틈은 "더 좋은 학습지"가 아니라 **"학습지 사기 전 단계"**.

### 4-3. 원가 공격: 번역·현지화가 정말 싼가?
- Oak 자료는 영어·영국 맥락(파운드화, 영국 계절·문화, 영어 음운 체계). 한글 문해에 무용, 상당수는 현지화 비용이 자체 제작과 비슷.
- 오픈 라이선스의 실익은 콘텐츠 절감이 아니라 **① 권위 차용("영국 국가 커리큘럼 기반"이 사실이 됨) ② 검증된 시퀀스·평가 구조 차용**. 이 인식 없이 "번역만 하면 된다"로 접근하면 원가 계산이 무너짐.

### 4-4. AI 공격: ChatGPT가 워크시트를 공짜로 만들어주는 시대
- PDF 콘텐츠 그 자체는 방어력 0. 학부모가 "7세 수학 워크시트 만들어줘" 하면 끝.
- **방어선**: AI가 대체 못 하는 것 = 검증된 12주 시퀀스(순서의 신뢰), 진단→처방 연결, 매주 오는 알림(실행 관리), 같은 코호트 커뮤니티. 콘텐츠가 아니라 **실행 시스템**을 파는 것으로 정의해야 생존.

### 4-5. 법·표시 공격
- "영국 국가 커리큘럼 기반"은 사실이라 성립. 단 "영국 정부 인증/제휴"로 오인시키면 표시광고법 위반 — 문구 심사 필요.
- OGL/CC BY 출처표시 누락, 제3자 저작물 미제거, IM v.360(CC BY-NC) 혼입이 3대 실수 포인트. 콘텐츠 파이프라인에 라이선스 체크 단계 명문화.
- 실시간 화상 교습을 넣는 순간 학원법·원격교습 신고 이슈 발생 — MVP는 콘텐츠+커뮤니티까지만.

### 4-6. LTV 공격: 6개월 시즌 상품, 고객 수명 1년
- 예비초등은 2월이면 끝나는 상품. 재구매 없음.
- **반영**: 매년 리필되는 코호트(연 30만)로 CAC만 낮으면 시즌 장사로 성립하지만, 성장하려면 초1-2 연장 상품(받아쓰기·수학 심화, IM/EL 자료의 본령)으로 밸류체인 연장이 전제.

## 5. 판정

- **원안("선진 교육자료를 가져와 알려준다") 그대로는 약하다**: 번역 콘텐츠 판매는 AI와 대기업 사이에서 협공당한다.
- **생존형 MVP**: 무료 크로스워크 진단(신뢰+리드) → 12주 실행 프로그램(콘텐츠가 아니라 시퀀스+알림+커뮤니티) → 초1-2 연장. 해외 커리큘럼은 전면이 아니라 신뢰 근거.
- **킬 기준(시즌 종료 시점)**: 진단 완료 2,000명 미만 or 채널 전환 25% 미만 or 유료 전환 1.5% 미만이면 중단/피벗. 검증 대상은 매출이 아니라 "진단→구독→구매" 전환 사슬.
- 1차 분석(육아 혜택 정보망)과의 시너지: 같은 타깃(5~7세 부모), 같은 채널(카카오), 같은 방어 논리(AI가 인용해도 대체 못 하는 도구). 혜택 정보 콘텐츠가 상단 퍼널, 본 프로그램이 수익화 하단이 되는 결합형이 단독안보다 강하다.
