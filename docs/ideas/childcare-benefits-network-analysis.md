# 사업성 검증: 전국 지원/행사 기반 지역 맞춤 육아 혜택 정보망

> 검증일: 2026-08-24 · 방식: 시장성 → 경쟁 → 기술/데이터 → SEO/AEO → 수익화 순으로 루프를 돌며 각 단계를 적대적(devil's advocate) 관점에서 재검증

## 최종 판정: ⚠️ 조건부 GO — 원안 그대로는 실패 확률 높음, 피벗하면 틈새 있음

원안의 3대 전제 중 2개가 사실 검증에서 깨진다.

| 원안의 전제 | 검증 결과 |
|---|---|
| 지자체 장난감 대여 API로 자동 수집 | ❌ **통합 API 없음.** 지자체별 파편화, 다수는 API 자체가 없고 개별 홈페이지 공지 |
| AI가 인용하면 트래픽·수익 발생 | ❌ **AEO 역설.** AI가 스텝바이스텝을 그대로 답하면 방문 없이 종결 → 쿠팡 클릭 0 |
| 보건복지부 API 기반 시설 정보 | ✅ 어린이집 정보공개포털 OPEN API, 전국 어린이집 정보 조회 API 실존 |

---

## 1. 시장성 분석

### 긍정 신호
- **출생아 수 반등**: 2026년 1분기 출생아 75,013명, 전년 대비 +14.8%. 수요 기반이 바닥을 치고 회복 중.
- **텐포켓/골드키즈 소비**: 출산율 0.7명대에도 육아용품 시장 5조 원 돌파, 유아동복만 2조 원(+9.1%, 여성복·남성복은 역성장). 아이 1명당 지출 단가가 높아 **제휴 수수료 관점에서 객단가가 좋은 카테고리.**
- **검색 수요 구조가 프로그래매틱 SEO에 적합**: "지역(229개 시군구) × 시설/사업 × 액션(신청방법·대기·후기)" 조합으로 롱테일 키워드가 수만 개 생성 가능. 개별 볼륨은 작지만 경쟁도 낮고 구매력 있는 타깃(신생아~미취학 부모)만 정확히 걸러진다.
- **정보 비대칭 실존**: 지원사업이 국가·광역·기초 3층으로 쪼개져 있고, 장난감도서관은 "매월 20~25일에만 회원 신청"(용인) 같은 지역별 디테일이 정부 포털에 통합돼 있지 않다. 아픈 지점(pain point)은 진짜다.

### 적대적 반론
- 반등해도 연 출생아 ~25만 명 수준. **TAM 자체가 구조적으로 작고, 사용자 생애가치가 짧다**(자녀가 취학하면 이탈, 고객 수명 5~6년).
- 정보 비대칭은 정부가 메우는 중이다(아래 경쟁 분석). 격차가 좁혀지는 속도가 사이트 성장 속도보다 빠를 수 있다.

**소결**: 시장은 축소가 아니라 "소수 정예 고단가"로 재편 중. 틈새는 있으나 창이 닫히는 중.

## 2. 경쟁 분석

### 1군 — 정부 (가장 위협적)
- **아이사랑 포털/앱**: 임신·출산·육아 정보 + 시간제보육 예약·입소대기·보육료 결제까지. 정보뿐 아니라 **신청 기능**을 독점.
- **복지로 + AI 챗봇 '복지니'**: 대화로 수급 자격 모의계산 → 신청 페이지 링크까지 연결.
- **AI 정부24**: 맞춤형 혜택 추천 → 실제 신청 연결률 54.9%. 연말 고도화 예정. **"내가 받을 수 있는 혜택 찾기"라는 코어 기능을 정부 AI가 이미 수행 중.**
- **서울 '몽땅정보통'**: 결혼~육아 혜택 통합 조회+신청. 광역 지자체가 직접 어그리게이터를 만드는 선례 — 타 지자체 복제 가능성 높음.
- 지자체 육아종합지원센터: 장난감도서관의 실제 운영 주체이자 1차 정보원.

### 2군 — 민간
- 임신육아 플랫폼(베이비빌리·마미톡 류): 출산율 최저에도 성장 중. 커뮤니티+기록 앱으로 리텐션 강함.
- 지원금 알림 앱(복지엄마, 아이지원 등): 개인 개발자 다수 진입 — **진입장벽이 낮다는 증거이자 차별화 실패 시의 미래.**
- **네이버 맘카페**: 지역 육아 정보의 실질 강자. "OO구 장난감도서관 어때요" 류 질문의 실제 검색 종착지.
- 기존 블로거: "용인 장난감도서관 신청·이용방법 3개점 비교" 같은 고품질 후기 글이 이미 상위 노출. 자동 생성 글이 실사용 후기를 이기기 어렵다.

**소결**: "혜택 찾아주기"는 정부 AI와 정면충돌, "지역 후기"는 맘카페·블로거와 충돌. 살아남는 포지션은 그 사이 — **전국을 커버하는 구조화된 최신 데이터**(맘카페는 파편적, 정부는 지역 디테일 없음)뿐이다.

## 3. 기술/데이터 적대적 분석 — 최대 리스크

- 어린이집/아이돌봄 API는 실존(공공데이터포털 15101155 등). 여기까진 성립.
- **장난감도서관은 API 세계가 아니다.** 서울장난감도서관, 대전, 달서구 등 전부 개별 사이트이고 공지사항·HWP 파일로 정보가 흐른다. "실시간 수집"은 실제로는 **229개 시군구 크롤러 + 수동 검증 운영**이며, 이는 1인 자동화 프로젝트의 비용 구조를 파괴한다.
- **틀린 정보의 비대칭 피해**: 신청 기간·휴관일·정원이 틀리면 사용자는 아이를 데리고 헛걸음한다. 육아 분야에서 이건 단순 이탈이 아니라 맘카페 박제감. 자동 발행일수록 이 리스크가 커진다 — **자동화가 강점이 아니라 약점이 되는 도메인.**

## 4. SEO/GEO/AEO 적대적 분석

- **AEO 역설(치명적)**: "OO구 장난감도서관 신청 방법"의 답은 3~4문장이면 끝난다. AI가 인용하는 순간 사용자는 답을 얻고 떠난다. **인용 ≠ 방문 ≠ 클릭.** 원안의 핵심 전략이 원안의 수익 모델을 죽인다.
- **행정 정보는 go.kr이 인용 우선권을 가진다**: AI 검색은 신청·자격 요건 같은 행정 질의에서 공식 출처를 우선 인용하는 경향 — 신생 개인 사이트가 정부 포털을 제치고 인용되기 어렵다.
- **대량 자동 발행 = 구글 scaled content abuse 정책의 정조준 대상.** 2024년 3월 코어 업데이트 이후 프로그래매틱 저품질 사이트 대량 제재 전례.
- **한국 육아 검색은 네이버 중심**인데, 네이버는 독립 도메인에 인색하고 블로그·카페·인플루언스 생태계가 유리하다. 쿠팡파트너스 자체가 저품질 사유는 아니지만(콘텐츠 품질이 관건), 자동 발행 + 관련성 낮은 제휴 링크 조합은 노출 누락의 전형적 패턴.

## 5. 수익화 적대적 분석

- **의도 미스매치**: "신청 방법" 검색자는 무료 혜택을 찾는 사람이지 지금 구매하려는 사람이 아니다. 정보성 트래픽의 제휴 전환은 통상 극히 낮다.
- 쿠팡파트너스 수수료 ~3%, 쿠키 24시간. 보수적 시나리오: 월 5만 PV × CTR 3% × 전환 5% × 객단가 5만 원 × 3% ≈ **월 11만 원**. 트래픽을 10배 키워도 인건비가 안 나온다.
- 진짜 수익은 트래픽이 아니라 **오디언스 자산**(카카오 채널/뉴스레터 구독자)에서 나온다: 지역 키즈 업체 제휴, 육아용품 브랜드 협찬, 유료 알림.

## 6. 생존 가능한 피벗

원안(API → 자동 발행 → 쿠팡)이 아니라:

1. **콘텐츠가 아니라 도구로**: "OO구 장난감도서관 **신청일 알림**"(매월 20일 오픈 등 지역별 신청 캘린더 + 카카오 알림). AI가 인용은 해도 **대체할 수 없는 기능**이 해자다. 알림 구독자 = 소유 가능한 오디언스.
2. **전국이 아니라 1개 광역부터**: 경기도(장난감도서관 22개 시 운영, 최대 볼륨)만 수동 검증 포함 완벽 커버 → 정확도로 맘카페 내 자연 인용 확보 → 검증 후 확장. 전국 자동화 먼저 깔면 부정확 데이터로 신뢰만 소진.
3. **AEO는 트래픽 수단이 아니라 브랜드 수단으로**: 구조화 데이터(FAQPage, HowTo, LocalBusiness 스키마)로 인용은 따내되, 수익은 인용이 못 뺏는 알림·비교 도구·커뮤니티에서.
4. 쿠팡파트너스는 "연령별 발달 장난감 → 대여로 먼저 체험 → 구매 링크" 같은 **대여-구매 연결 동선**에만 자연 삽입(저품질 회피 + 의도 일치).

## 7. 판정 요약

- **시장성**: 있음(출생아 반등 + 텐포켓 고단가 + 롱테일 공백). 단, TAM 소형·고객 수명 단기.
- **경쟁**: 정부 AI(복지니, AI정부24)가 코어 기능을 잠식 중. 순수 정보 어그리게이터로는 2~3년 내 존재 이유 소멸 위험.
- **원안 실행 시 예상 실패 지점**: ① 장난감도서관 API 부재로 자동 수집 붕괴 → ② 크롤링 데이터 부정확 → ③ 자동 발행 대량 콘텐츠가 구글·네이버 양쪽에서 제재 → ④ 살아남은 트래픽도 AEO에 뺏기고 쿠팡 전환 미미.
- **권고**: 원안 폐기가 아니라 재설계 — "자동 발행 정보망"이 아니라 **"1개 광역 완벽 커버 + 신청 캘린더 알림 도구"**로 시작. MVP 4주(경기도 장난감도서관 30곳 DB + 카카오 알림 채널)로 알림 구독 수요부터 검증할 것.
