# 조사 노트: 예비초등 교육 관련 상업적 이용 가능 오픈데이터

> 조사일: 2026-08-24 · 목적: 예비초등(취학 전~초1 전환기) 교육 사업에 상업적으로 쓸 수 있는 오픈데이터/공공저작물 식별
> 2차 수정: **국내 사업 전제로 재판정** — 해외 전제에서 막혔던 AI허브가 해금됨

## 국내 사업 기준 재판정 (최종)

| 소스 | 해외 전제 | **국내 전제** |
|---|---|---|
| 교육과정 고시문 (누리과정·2022 개정) | ✅ 자유 | ✅ 자유 (저작권법 7조, 동일) |
| 공공누리 1유형 데이터 | ✅ 출처표시 | ✅ 출처표시 (동일) |
| **AI허브 데이터셋** | ❌ 국외 반출 불가 | ✅ **사용 가능** — 모델 학습·서비스 영리 활용 OK, 단 출처 명시 + 원본 재배포/판매 불가 |
| "해외 인증" 마케팅 문구 | 허위 표시 | 국내에서도 표시광고법 리스크 — 실재 근거(PISA 등)만 인용 가능 |

### 국내 사업에서 쓸 만한 AI허브 데이터셋 (예비초등 관련)
- [자유대화 음성 — 소아·유아 혼합 (3~6세/7~10세)](https://www.aihub.or.kr/aihubdata/data/view.do?dataSetSn=108)
- [한국어 아동 음성 데이터 (4~6세 낭독)](https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=540)
- [어린이 음성 데이터셋](https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=266)
- [학습용 아동 영어 음성 데이터](https://aihub.or.kr/aihubdata/data/view.do?dataSetSn=541)
- 활용 예: 한글 낭독 평가, 발음 교정, 아동 특화 STT 기반 학습 앱 — 아동 음성은 성인 대비 인식률이 낮아 이 데이터가 실질적 차별화 요소

### 국내 학부모용 신뢰 마커는 "해외 인증"이 아니라 국가 준거
- "국제 인증" 표현은 근거 없음(그런 인증 제도 자체가 없음) → 부당 표시·광고 리스크
- 실제로 먹히고 증빙 가능한 문구: **"교육부 2022 개정 교육과정 초1 성취기준 준거", "누리과정 연계", "국가기초학력 진단 기준 반영"** — 전부 오픈데이터(고시문)로 검증 가능해 오히려 강력
- 추가 소스: [국가기초학력지원포털](https://www.basics.go.kr) (초등 입학 전후 진단·보정 자료)

## 전제 교정: "해외에 인증된 한국 예비초등 교육과정"은 존재하지 않는다

- 누리과정(3~5세)·초등 교육과정은 **교육부 고시**이지 국제 인증(certification/accreditation) 대상이 아니다. IB처럼 국제기구가 인증하는 체계가 아님.
- 한국 교육의 해외 신뢰는 **평판 기반**: PISA 상위권 성적, K-에듀테크 수출 실적(유아 영어 프로그램 170만 달러 수출 계약, 중앙아시아 K-유아교육 진출 등).
- 따라서 해외 마케팅 문구는 "internationally certified"가 아니라 **"based on Korea's national curriculum (Nuri Curriculum / 2022 Revised National Curriculum)"**로 써야 법적·사실적으로 안전하다.

## 상업적 이용(해외 포함) 가능한 소스

### 1. 교육과정 고시문 원문 — 아예 저작권이 없음 (가장 강력)
- 저작권법 **제7조 2호**: 국가·지자체의 고시·공고·훈령은 저작권 보호를 받지 못하는 저작물.
- **2019 개정 누리과정 고시문, 2022 개정 교육과정(초등 포함) 고시문**은 번역·재구성·상업화·해외 사용 전부 자유. 출처표시 의무조차 법적으로는 없음(신뢰상 표기 권장).
- 원문 확보처: NCIC 국가교육과정정보센터(ncic.re.kr), 교육부 고시 페이지.

### 2. 공공누리 제1유형(KOGL Type 1) 자료 — 출처표시만 하면 상업+변형+해외 OK
- 제1유형: 출처표시 / 상업적 이용 가능 / 변경 가능. (제0유형은 표시조차 불요)
- 해당 데이터 예:
  - [교육부 유치원 공시자료 다운로드](https://www.data.go.kr/data/15036719/fileData.do) (공공데이터포털)
  - [유치원알리미 Open API](https://e-childschoolinfo.moe.go.kr/openApi/openApiList.do)
  - [학교알리미 공개용 데이터](https://www.data.go.kr/data/15014351/fileData.do)
  - KEDI 교육통계서비스 KESS(kess.kedi.re.kr) 통계간행물
  - 어린이집정보공개포털 OPEN API / 전국 어린이집 정보 조회 API
- **주의: 자료마다 유형 확인 필수.** 제2유형(상업 금지)·제3유형(변경 금지)·제4유형(둘 다 금지)이 섞여 있다.

## 함정 (쓰면 안 되거나 개별 협의 필요)

| 소스 | 문제 |
|---|---|
| **AI허브(AI-Hub)** | 원본 데이터 **국외 반출 불가**, 원본 재배포 불가. 해외 서비스용으로 사용 불가 — 학습된 모델의 영리 활용만 국내 중심으로 허용 |
| i-누리·에듀넷 놀이자료/교수학습자료 | 공공누리 유형이 자료마다 다름, 상업 금지(2·4유형) 다수 — 건별 확인 필요 |
| EBS 콘텐츠(한글이 야호 등) | 오픈데이터 아님. 별도 라이선스 계약 대상 |
| 교과서(검정·인정) | 민간 출판사 저작물. 국가 교육과정과 별개로 저작권 있음 |

## 실무 결론

오픈데이터로 확보 가능한 것은 **① 커리큘럼 프레임(고시문 — 저작권 無) ② 행정·통계 데이터(KOGL 1유형)**이지, 완성된 교육 콘텐츠(교재·영상·워크시트)가 아니다. 해외 상업화 구조는:

1. 누리과정·초등 교육과정 고시문을 골격으로 번역/재구성 (법적 리스크 0)
2. 실제 학습 콘텐츠는 자체 제작 → 오히려 저작권 클린해서 수출에 유리
3. KOGL 1유형 자료 사용 시 출처표시(기관명·저작물명·다운로드 URL) 준수
4. "국제 인증" 표현 금지 → "Korea's national curriculum-based" 포지셔닝
