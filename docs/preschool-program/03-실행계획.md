> 원칙: **콘텐츠를 다 만들고 파는 게 아니라, 1주차에 팔 수 있는 걸 만들어 판다.**

## Phase 1 — 8~9월: 자산 만들기 (매출 0원 구간)

### 1주차 · 원본 확보
- [ ] ACARA V9 **Foundation Year** 성취기준 다운로드 → English / Mathematics / Health & PE
- [ ] gov.uk에서 **EYFS 법정 프레임워크 + Development Matters** 원문 PDF 다운로드 (⚠️ Twinkl 등 제3자 사이트 자료는 절대 사용 금지)
- [ ] NCIC에서 **2022 개정 교육과정** 초등 1학년 성취기준 + 입학초기적응활동 다운로드 (공공누리 유형 배지 확인)
- [ ] `자료출처.csv` 생성 — 자료명 / URL / 라이선스 / 취득일 / 사용처

### 2주차 · 매핑
- [ ] 3개 원본의 "학교 적응·자기조절" 항목을 한 표로 정렬
  → `EYFS PSED 항목 | ACARA Foundation 대응 | 2022 개정 대응 | 우리 활동 번호`
- [ ] 30일치 주제 확정 (아래 4주 구성안 참고)
- [ ] **원문 번역이 아니라 재구성**임을 문서로 남기기 (Common Core는 개작 금지이므로 애초에 제외)

### 3주차 · 첫 상품 = PDF 워크북
- [ ] 30장 활동지 제작. 각 장 구성: `아이 활동(5분)` + `부모 가이드 한 문단` + `오늘의 한마디`
- [ ] 표지 + 라이선스 고지 페이지 + 사용법 2p
- [ ] 삽화는 공유마당 만료저작물 또는 자체 제작 (원문 PDF의 사진·삽화 재사용 금지)

### 4주차 · 판매 개시 ← **여기서 첫 매출**
- [ ] 네이버 스마트스토어 개설 + 통신판매업 신고
- [ ] 『입학 전 30일 학교 갈 준비 워크북』 **12,900원** 등록
- [ ] 무료 샘플 5일치 배포 → 리드 수집(이메일)

**Phase 1 목표: 매출 10~30만원, 이메일 리스트 100명**

## Phase 2 — 10~11월: 유입 만들기

- [ ] 블로그 개설, 주 2회 발행. **10월까지 20편**이 목표 (검색 색인에 시간이 걸립니다)
- [ ] 쿠팡파트너스 가입 → 아래 3개 축으로 콘텐츠 배치
  - **입학 준비물 체크리스트** (책가방·실내화·2B연필·이름표 스티커 …) ← 제휴 링크 밀도 최고
  - **예비초등 학부모 Q&A** (화장실, 급식, 알림장, 하교 동선)
  - **한글 해득 진도 점검** (경쟁이 심하지만 검색량이 커서 유입용으로 유효)
- [ ] 모든 게시물 본문 앞에 대가성 문구 삽입
- [ ] 인스타그램 카드뉴스 병행 (캡션 첫 줄에 대가성 문구)

**Phase 2 목표: 월 PV 20,000, 쿠팡 월 3~10만원, 워크북 월 30만원**

## Phase 3 — 12~2월: 시즌 수확 + 구독 전환 🔥

- [ ] **12월 첫 주** 구독 오픈 — 취학통지서 발송 시점에 맞춤
  - 정가 **4,900원/월**
  - **선착순 500명 990원 평생 고정** (기존 회원 가격은 이후 절대 인상하지 않음)
  - 결제는 **웹 PG**로. 인앱결제 30% 수수료는 이 가격대에서 치명적
- [ ] 워크북 구매자 전원에게 구독 전환 안내 (가장 높은 전환율이 나오는 경로)
- [ ] 매일 1개 활동 공개 + 주간 부모 리포트
- [ ] 1월: 두 번째 워크북(『한글 해득 30일』) 출시 → 번들 판매

**Phase 3 목표: 구독 200~400명, 쿠팡 월 20~40만원, 총 월 100만원 도달**

## Phase 4 — 3월 이후: 시즌 밖에서 버티기

3월에 입학이 끝나면 **검색량이 급감합니다.** 여기서 대부분이 무너집니다. 대비책 두 가지:

1. **대상 확장** — "입학 전"에서 "초1 1학기 적응"으로 이어붙이기 (3~7월 수요)
2. **가격 인상** — 과정이 늘었으므로 **신규 가입가만** 6,900원으로. 기존 회원은 그대로.
   → 법적으로 재동의 불필요하고, 기존 회원의 락인이 강해집니다.

```

[부모 가이드]  "오늘은 이렇게 물어보세요" — 3~4문장 스크립트
[체크]        아이가 스스로 표시하는 칸
```
