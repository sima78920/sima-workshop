# EP001 딸기속 — 컷별 생성 프롬프트 패키지

> 대상 파이프라인: **미르 로컬 GPT 이미지 생성 + 로라 갤러리 API** (크레딧 소모 0).
> 전략: **정지 이미지 우선** — 아래 이미지 12장을 로컬에서 뽑고, 이미지→영상 변환(줌/팬 모션)은 편집 단계에서 처리하거나 필요 컷만 image-to-video 모델 사용.
> 스토리보드 타임코드(EP001_딸기속.md)와 1:1 매핑. 프롬프트는 엔진 중립 영어 + 한국어 주석.

## 공통 설정

**스타일 앵커 (모든 프롬프트 앞에 고정):**
```
isometric cutaway cross-section style, ultra-detailed miniature diorama, warm soft studio lighting, bright cheerful colors, clean pastel background, child-friendly educational illustration
```

**공통 네거티브:**
```
scary, dark, gore, realistic blood, horror, cluttered, text, watermark, blurry
```

**로라(LoRA) 운용 노트:**
- 채널 그림체 고정용 로라를 하나 정해 전 컷에 동일 적용 (가중치 0.7~0.8 권장 시작점) — 그림체 일관성은 로라가, 구도는 프롬프트가 담당
- 파고(두더지 마스코트) 등장 컷(#1, #12)은 **마스코트 시트(Drive: mascot-persona.md 참조 이미지)를 레퍼런스로** — 로라 학습 전까지는 img2img/레퍼런스 모드 사용
- 세포 애니메이션 2컷(#8, #11)은 그림책 톤이 더 강해야 하므로 스타일 앵커의 "isometric cutaway"를 "storybook illustration"으로 교체

## 이미지 → 영상 변환 가이드 (선택)

- 기본: 정지 이미지 + 편집 모션(줌인/팬/스케일)만으로 45~52초 완성 가능 — 추가 생성 비용 0
- 더 살리고 싶은 컷 3개만 image-to-video 권장: #3(과즙 반짝임), #8·#11(세포 애니 모션) — 로컬 도구가 없으면 이 3컷만 Higgsfield(start_image 방식) 견적 뽑아서 결정
- 절단 순간의 실사감이 필요하면 #2→#3을 keyframe(start/end image) 변환
