# /osmu <에피소드> — 원소스 멀티유즈

## 시작 전 (필수)

`studio/코어.md` → 에피소드 md → 최신 `studio/트렌드/리포트/`(해시태그·음원 트렌드 참조)를 읽는다.

## 절차

1. `studio/OSMU/_템플릿_OSMU.md` 구조로 `studio/OSMU/EP{번호}_osmu.md` 생성:
   - 플랫폼별 길이/훅 타이밍/자막/해시태그/음원 변환 규칙 채움
   - 틱톡 음원은 최신 트렌드 리포트의 tiktok_music_trending 결과에서 후보 제시
   - 복붙 패키지: 플랫폼별 제목/설명/해시태그 완성본
2. **발행 게이트**:
   - 유튜브/릴스: 발행 API 없음 — 수동 업로드용 복붙 패키지가 산출물
   - 틱톡: `tiktok_prepare_publish` 초안 검토 항목 정리까지만. **`tiktok_publish` 호출 금지 — 미르 승인 필요**
   - AI 고지(합성 콘텐츠 설정) 체크리스트 필수 포함

## 종료

mirOps 폴백 기록 + 보고(결론→바뀐 것→미르가 할 것: 업로드 순서와 복붙 패키지 위치) + 검수 3줄.
