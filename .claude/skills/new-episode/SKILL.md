# /new-episode <채널 A|B> <주제> — 에피소드 기획

## 시작 전 (필수)

`studio/코어.md` → 해당 `studio/채널/{채널}/채널.md`(톤·스타일앵커·안전톤 준수) → `studio/기회/주제백로그.csv`에서 주제 행과 스코어카드 → 관련 `벤치마크/해부/` 리포트를 읽는다.

## 절차

0. **출처 게이트 (선행 필수)**: `studio/출처/출처대장.csv`에서 주제 관련 자료를 확인한다. 구조 근거(벤치마크 해부) 1건 + 사실 근거(논문/뉴스/도서 등 신뢰도 상·중) 2건 미만이면 **먼저 /research를 실행**하고 돌아온다. 출처대장에 없는 사실은 대본에 쓸 수 없다.
1. `studio/채널/_템플릿_에피소드.md` 구조로 `studio/채널/{채널}/EP{다음번호}_{주제슬러그}.md` 생성:
   - 근거 섹션부터 채운다 — 사용할 출처 [S###]와 각각에서 가져올 내용
   - 훅은 "즉시 실행, 설명 금지" 원칙 + 벤치마크 실측 구조 인용 (예: [S001] 0:00 즉시 실행 훅)
   - 대본: 모든 사실 주장 문장 끝에 [S###] 태그. 채널 B는 "진짜로는~" 보정 문장 태그 필수
   - **스토리보드: 0.1초 단위 타임코드** — 컷 경계·카메라 무빙·사운드 온셋·자막 in/out 전부 (예: 0.0–1.2s)
   - 컷별 비주얼 키워드는 채널 스타일앵커 뒤에 붙는 형태로 작성
   - 내레이션: 문장당 7~10단어, 의성어, 아이 눈높이
   - 지표 4종 목표치 기입
1-1. **자체 검증**: 출처 태그 없는 사실 문장 0건 / 스토리보드 전 행 0.1초 타임코드 / 훅의 벤치마크 인용 — 하나라도 미달이면 보완 후 제출.
2. **비용 견적(무료)**: 필요 시 `models_explore`로 모델 추천, `shorts_studio_create`의 `get_cost:true`로 무료 견적만. **실제 생성 호출 금지** — 제작 지시란에 "[미르] 승인 후 [CX] 실행"으로 남긴다.
3. 채널.md의 에피소드 표에 1행 추가.

## 금지

generate_*·shorts_studio 실행·업로드·발행. 전부 "승인 필요".

## 종료

mirOps 폴백 기록 + 보고(결론→바뀐 것→미르가 할 것: 승인 여부 + 승인 시 실행 명령 복붙) + 검수 3줄.
