# /research <주제> — 자료 수집·검증

## 시작 전 (필수)

`studio/코어.md` → `studio/출처/출처대장.csv`에서 해당 주제의 기존 등록 자료 확인 (중복 수집 방지).

## 절차 (읽기 전용 도구만: WebSearch/WebFetch)

1. **바이럴 콘텐츠**: WebSearch로 주제 관련 고조회수 영상/포스트 탐색 (영/한 병행). 억대뷰급 유튜브 영상을 찾으면 `/benchmark` 연계를 보고에 제안.
2. **학술 자료**: scholar.google.com·semanticscholar.org·pubmed 계열을 WebSearch `site:` 필터로 검색 → WebFetch로 초록 확인. 피어리뷰 여부로 신뢰도 판정.
3. **뉴스·도서·공식자료**: 주요 매체 보도(복수 매체 교차 확인), 공식 통계·기관 자료, 관련 도서.
4. **신뢰도 판정**: 상(피어리뷰/공식 통계/조회수 실측) · 중(복수 매체 보도/단행본) · 하(단일 매체/블로그 — 대본 근거로는 사용 금지, 참고만).
5. **등록**: `출처대장.csv`에 S### 연번으로 append + 핵심 자료는 `출처/S###_{슬러그}.md` 자료노트 생성(템플릿 준수). 핵심 주장·수치는 대본에 인용 가능한 단위로 쪼갠다.
6. 자료가 5건 이상이면 수집·요약을 haiku 서브에이전트에 병렬 위임.

## 금지

과금 도구, 발행, 삭제, 기존 출처 행 수정(추가만 — 정정은 새 행 + 비고).

## 종료

mirOps 폴백 기록 + 보고(결론 → 등록된 출처 목록[S### 포함] → 미르가 할 것) + 검수 3줄.
